# Descargas Lufer

MVP de una herramienta web de extracción y descarga de contenido multimedia.

## V1

- Next.js 16
- React 19
- API Route en Node.js
- YouTube como primera plataforma
- Consulta de metadatos y formatos
- Descarga de formatos progresivos disponibles
- Sin almacenamiento permanente de videos

## Desarrollo

```bash
npm install
npm run dev
```

Abrir `http://localhost:3000`.

## Despliegue

El proyecto está preparado para conectarse a Vercel desde el repositorio `victorfa27/descargas-lufer`.

## Importante

La disponibilidad de formatos depende del contenido y de los cambios técnicos de la plataforma de origen. El proyecto no debe utilizarse para infringir derechos de autor, controles de acceso o restricciones de una plataforma.
